# Advanced Excel – Employee Data Analysis & HR MIS

## Project Overview
This project demonstrates practical applications of Microsoft Excel for employee data analysis and HR-related business calculations. It focuses on conditional logic, salary-based eligibility, employee classification and analytical reporting.

## Dataset Overview
The employee dataset includes:
- Employee ID
- First Name and Last Name
- Joining Date
- Gender
- Marital Status
- Department
- Basic Salary
- Region

## Excel Concepts & Functions Used

### 1. Conditional Eligibility Analysis
- Used `IF()` and `AND()` functions to identify female employees earning less than ₹50,000.
- Classified eligible employees for gift allocation.

### 2. Salary-Based Bonus Calculation
- Identified employees earning less than ₹30,000 in the CCD department.
- Applied ₹9,000 bonus eligibility.

### 3. Employee Retirement Classification
- Extracted joining years from employee joining dates.
- Classified employees who joined before 1980 as retired, according to the project rule.

### 4. Department-Based Bonus Analysis
- Identified employees in Sales or Marketing departments earning less than ₹45,000.
- Applied ₹25,000 bonus eligibility.

### 5. Employee Gift Allocation
- Applied ₹1,500 Amazon voucher eligibility to employees, excluding Directors and CEOs.

## Skills Demonstrated
